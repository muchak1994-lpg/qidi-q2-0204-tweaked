# OrcaSlicer profiles — origin and license

The profiles in this folder are OrcaSlicer *user presets*. Each one only stores the settings that differ from a QIDI Q2 system profile shipped with OrcaSlicer (`"inherits"`), plus the end G-code in the printer profiles, which is QIDI's own end G-code with one added line (`M106 P3 S0`).

OrcaSlicer, including its bundled printer profiles, is licensed under the GNU Affero General Public License v3.0 (https://github.com/SoftFever/OrcaSlicer). These derived files are distributed under the same license, AGPL-3.0.

They contain no printer address and no API key.
